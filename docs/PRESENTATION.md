# Презентация · 7 минут
1. 0:00–1:00. Объяснить маркировку «СИМУЛЯЦИЯ», 6 сотрудников и 3 условные зоны, автономность карты. Нажать сброс, выбрать первого сотрудника, скорость ×60.
2. 1:00–2:00. Начать смену. Показать появление и движение точки, счётчики и карточку трекера. Выйти из зоны: точка действительно меняет координаты, алгоритм создаёт инцидент. Повторить кнопку: дубля нет. Подтвердить инцидент, показать фильтр подтверждённых.
3. 2:00–3:00. Потерять GPS. Точка исчезает, состояние «Нет GPS», неизвестное время отдельно. Восстановить GPS, вернуться в зону; показать журнал переходов. Низкий заряд → отдельное уведомление.
4. 3:00–4:30. Перейти на экран сотрудника через меню (без новой вкладки). Показать общую смену, статус и уведомления. Добавить демо-фото, завершить задание. Изображение — иллюстрация, не реальная съёмка. Вернуться в CRM и показать увеличившийся счётчик фото.
5. 4:30–5:30. Начать смену у второго сотрудника. Пауза фиксирует время и точки; продолжить. Показать выбор человека, поиск и журнал выбранного.
6. 5:30–6:30. Завершить смену первого сотрудника, открыть табель, объяснить категории и сумму. Скачать CSV. История событий сохраняется; вне смены позиция не отображается.
7. 6:30–7:00. Сброс очистит все демонстрационные данные. Открыть ТЗ: промышленный backend, адаптеры устройств, права, согласие, offline и эскалации — будущая работа. Не обещать реальные интеграции, договорные сроки или юридическую готовность.

Перед встречей: `npm ci && npm test && npm run build`, `npm run preview`; открыть адрес 4173. Не использовать dev/HMR для offline. При обновлении страницы сеанс потеряется. Публичный доступ без подтверждённого deployment не обещать.
