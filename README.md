# JASYL · Astana Green CRM Demo
Презентационная CRM озеленения на русском с мобильным интерфейсом сотрудника. **СИМУЛЯЦИЯ: вымышленные сотрудники, условные координаты, синтетические иллюстрации.**

## Запуск
Требуется Node.js 22.12+ или 24 и npm.
```sh
npm ci
npm test
npm run build
npm run preview
```
Открыть http://127.0.0.1:4173 (CRM), http://127.0.0.1:4173/#mobile (сотрудник). Для разработки `npm run dev`. Сервер по умолчанию доступен только на этом Mac. Для смартфона требуется отдельно согласованный HTTPS-хостинг; localhost телефона не является адресом Mac.

## Что работает
Dashboard, автономная схема Астаны и 3 условных полигона, 6 вымышленных сотрудников, выбор/поиск, движение GPS, смены, выход/возврат, потеря/восстановление сигнала, заряд, инциденты/фильтры/подтверждение, табель и CSV, задания и синтетические фото, мобильный экран. Общая модель `src/model.ts`; время движется ×1/10/60, пауза останавливает его. Данные хранятся только в памяти вкладки, обновление страницы и сброс начинают новый сеанс. Между отдельными вкладками синхронизации нет: презентуйте переключением разделов.

## PWA
Manifest и service worker; в production preview посещённые ресурсы кэшируются после первого открытия. Offline shell не означает offline-синхронизацию данных. Установка зависит от браузера и платформы; нативный Flutter ещё не реализован. Проверяйте offline на build/preview, не на Vite HMR.

## Ограничения
Нет backend, базы, реальной авторизации/ролей, сети трекеров, камеры, push/SMS, финансов и платных сервисов. Геометрия вычисляется, однако карта схематическая, не навигационная; временная фильтрация геопереходов и сетевые таймауты описаны в ТЗ, в демо достоверные кнопочные переходы немедленные. Текущий табель суммарный за сеанс, без архива отдельных смен. KZ предусмотрен требованиями, перевод не включён. Не использовать для управления реальными людьми.
