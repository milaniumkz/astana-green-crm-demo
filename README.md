# JASYL 2.0 · Astana Green CRM Demo

**[Открыть стенд](https://milaniumkz.github.io/astana-green-crm-demo/)** · **[Мобильный экран](https://milaniumkz.github.io/astana-green-crm-demo/#mobile)**

Реальная интерактивная карта Астаны OpenStreetMap, вымышленные сотрудники и синтетические GPS-маршруты. Презентационная веб-CRM, не система для фактического контроля работников.

## Запуск
Node.js 22.12+ или 24, npm. Без ключей и платных сервисов.
```sh
npm ci
npm test
npm run build
npm run preview
```
CRM: http://127.0.0.1:4173/ . Сотрудник: http://127.0.0.1:4173/#mobile . Сервер доступен только на этом Mac. Разработка: `npm run dev`. Публичный HTTPS-адрес выше доступен и со смартфона.

## Что добавлено в 2.0
- Leaflet/OSM: улицы и ориентиры Астаны, zoom/pan, рабочие полигоны, кликабельные маркеры, направление, следы последних GPS-точек, точность и последняя известная позиция. Синтетические границы явно подписаны.
- Журнал: дата/время Asia/Almaty, сотрудник/бригада/трекер/зона, источник, точность, важность, статус, подтверждение с автором и комментарием, карточка и точка события на карте. Поиск, фильтры и CSV.
- Табель: отдельные смены, план/факт, перерывы, внутри/снаружи/неизвестно, опоздание/раннее окончание, период и бригада, агрегаты, временная шкала, CSV с теми же фильтрами.
- История 12–14 октября 2026: 18 явно синтетических смен; текущая симуляция — 15 октября. В табеле по умолчанию только текущий день/симуляция; для истории измените даты и набор данных.
- Пауза, ×1/10/60/300, шаг +1 мин, 11 этапов сценария, сброс. Перерыв не учитывается повторно как время в зоне. GPS-loss — неизвестное положение, не прогул.
- Версионированное сохранение модели в localStorage. Перезагрузка сохраняет сеанс, время отсутствия браузера не начисляется. Фильтры не сохраняются. Один показ — одна вкладка; между устройствами синхронизации нет.

## Показ за 5–10 минут
Нажмите «Сбросить сеанс», затем «Следующий этап» и проходите сценарий. После выхода откройте «Разобрать», введите комментарий и подтвердите. Переключайтесь между картой, журналом, табелем и экраном сотрудника. [Полный сценарий](docs/PRESENTATION.md).

## Карта и offline
Используется https://tile.openstreetmap.org/{z}/{x}/{y}.png с видимой атрибуцией © OpenStreetMap contributors. [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) проверена 15.10.2026: только видимые тайлы, браузерный HTTP-кэш, без массового скачивания и offline-предзагрузки. Service worker OSM-тайлы не перехватывает. Для реальной подложки нужен интернет; при ошибках виден статус и доступна отдельно подписанная авторская схема. Схема не содержит улиц и не выдаётся за OSM. PWA shell кэширует только посещённые ресурсы приложения; установка зависит от браузера.

## Границы демо
Нет backend, реальной авторизации, устройств/операторов GPS, камеры, push/SMS, payroll, промышленной offline-очереди или нативного Flutter. Достоверные кнопочные координатные переходы немедленные; production debounce/timeouts описаны в ТЗ. Маршруты не являются дорожными маршрутами. Исторические смены заранее сгенерированы; текущие события и интервалы вычисляются действиями. KZ — структура требований, полный перевод не выполнен. Не вводите реальные персональные данные в публичное демо.
